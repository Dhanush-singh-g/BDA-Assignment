    What happens to the data?
    

    MongoDB stores the source records. Python joins food and nutrient records into prepared files, which are uploaded to HDFS.
    

    Branch 1 · Calculate with MapReduce
    Read prepared HDFS files → filter negative amounts → calculate counts, totals and averages.
    Branch 2 · Clean with Pig, query with Hive
    Read the same prepared HDFS files → Pig cleaning → Hive Text and RCFile tables → compare answers, query time and storage.
    

    Pig cleans the prepared input for Hive. It does not clean the MapReduce output or change MongoDB records.

    What does each HDFS command do?
    

    1. mkdir — create folders inside HDFS.
    2. put — copy a local file into HDFS.
    3. cat — display a file stored in HDFS.
    4. get — download an HDFS file to the local machine.
    5. rm -r — delete the temporary demonstration folder from HDFS.
    

    What is a checked download? The program uploads a small probe file, downloads it and compares the bytes. Matching bytes confirm that the retrieved file is unchanged. The probe and temporary copies are cleaned up afterward; the analytical input/results are retained.
    

    Recorded file-operation evidence
    The demo uploads files, downloads/reads a probe and checks its bytes, then deletes only its own temporary demo folder.     Hive = SQL questions about files in HDFS
    

    Example question: “What is the average recorded protein amount for each food type?” We ask the same question of two tables containing the same cleaned records.
    

    Text table
    nutrients_text points to Pig’s cleaned, tab-separated text files. The underlying rows are human-readable.
    RCFile table
    nutrients_rcfile holds the same rows in a binary format arranged by columns within row groups, with gzip compression. Read it through Hive.
    

    Created once per processing run, reused for every query. Each table can contain multiple HDFS files. Repeating a query reads these tables; it does not recreate both datasets. Each execution saves its own answer and log files.
    

    1. Same answers? Check that counts, totals and averages match.
    2. Query time? Measure how long the same question takes.
    3. Storage size? Measure the space occupied by each format.
    

    Recorded Hive evidence
    nutrients_text reads the cleaned Pig output as Text; nutrients_rcfile stores the same rows as RCFile with gzip configured. The comparison includes both file layout and compression.
